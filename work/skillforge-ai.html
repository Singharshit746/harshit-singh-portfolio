Personalized learning platform · SIH internal, 2026

SkillForge AI

SkillForge started as a learning problem: people do not always know which skills they are missing for a role, and generic course lists do not close those gaps. The platform looks at competency, then generates role-specific recommendations instead of a single static syllabus.

There are two sides to the product. Learners get a skill profile, competency tracking, and an adaptive path. Administrators get dashboards for the same data. Assessments sit in the middle. The system generates source-grounded MCQs and quizzes from learning materials, marks them, and feeds that result back into the profile.

The loop is closed on purpose: Profile, Assess, Recommend, Learn, Reassess. Each pass is meant to update competency scores so the next recommendation is not the same as the last one.

I built this with a 6-member team for the Bennett University internal Smart India Hackathon in 2026. My work was the frontend, database connectivity, AI-integrated workflows, and API-driven features. The project reached the Top 100 teams in that internal selection process. A public GitHub repository is not listed yet.
