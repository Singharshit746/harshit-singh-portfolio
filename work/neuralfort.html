Mental health AI assistant

NeuralFort

NeuralFort is a conversational assistant focused on mental health support. The point was not a novelty chatbot. It was a place to talk in context, with replies that stayed with what the person had actually said.

I built a responsive frontend and wired it to backend APIs so the conversation could happen in real time. Most of the quality work was in the prompts: adjusting how the model was asked to respond so the exchange felt more usable and less generic.

The architecture was set up so later pieces could plug in, including sentiment analysis and personalized recommendations. Those pieces are not built yet. They are a direction, not a claim about the current product.
