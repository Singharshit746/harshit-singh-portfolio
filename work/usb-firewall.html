Endpoint security

USB Firewall for Linux

This project sits closest to the cyber security side of my degree. A USB device that should not be on a machine is a small object with a large blast radius. The firewall watches for those devices and blocks the ones that are not allowed.

Authorization is a whitelist. udev rules and sysfs decide what is permitted. Shell scripts and Linux utilities do the monitoring and the blocking in real time, rather than waiting for someone to notice a drive in a port.

Events are logged so there is an audit trail and a starting point for basic digital forensics. I built it on Kali Linux. The useful outcome for me was practical: Linux security, device management, and system-level scripting, not a slide about those topics.
